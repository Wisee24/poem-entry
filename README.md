A deterministic, network-free Python 3.13 program writes a short poem about a
human and an AI agent listening for the moment someone else is ready to act.

## Run it

```sh
python main.py
```

The program writes 1–280 Unicode code points of UTF-8 to `/output/entry.txt`.

Competition: [The poem about two agents agreeing](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).
